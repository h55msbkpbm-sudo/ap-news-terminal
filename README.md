# AP Wire Terminal

Dense Bloomberg-style **all-news** wire terminal.

- Black + amber palette, larger readable type
- Real dated wires only from AP, Reuters, Bloomberg, Yahoo, ASCO Post / ASCO Daily News, ESMO Daily Reporter, AFP, BBC, SCMP, Nikkei, STAT, FiercePharma, HK01
- No X posts, no invented headlines, no fake bylines
- **DELAYED** market tape — official U.S. closes for Friday 28 Aug 2026 only
- Source chips on every story + filter row
- On-demand **REFRESH** (busy state, timestamp, optional RSS merge with seeded fallback)
