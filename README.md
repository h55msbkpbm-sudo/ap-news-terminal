- Larger readable type (18px base)
- Real dated wires only (AP, Reuters, Bloomberg, Yahoo, ASCO Post, ASCO Daily News, ESMO Daily Reporter, AFP, BBC, SCMP, Nikkei, STAT, FiercePharma, HK01)
